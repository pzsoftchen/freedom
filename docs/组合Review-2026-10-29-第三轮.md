## 3. 压力测试（含"战术上沿"这个新发现）

| 情景 | S1 全球 risk-off |
| --- | ---: |
| 当前（74% 现金） | **−7.47%** |
| 完全部署到战略锚（权益 37%） | **−14.17%** |
| **战术带上沿**（A股 32 / 海外 12 / 黄金 7，现实可触达） | **−16.53%** ⚠️ |
| 极端（权益 80% 硬顶全触达） | −21.44% |

**发现 1**：单看战略锚压力 −14.17% 在 15% 预算内；但如果"便宜"同时触发战术超配到上沿，压力约 **−16.5%**，**超出 15% 预算 1.5pp**。极端 80% 权益硬顶可达 −21%。

**建议**（二选一）：
- 把 `equityCapPct` 从 80 降到 **70**（风险资产上限收紧，战术上沿压力回到 ≈−15%）；
- 或接受 −16.5% 作为真实上限（战术超配本就是"便宜时多担一点风险"的代价）。

## 4. 部署节奏：30% 偏慢

按当前缺口模拟（单次 10% 硬顶、月度执行）：

| 节奏 | 投完 14.26 万需要的月数 |
| --- | ---: |
| **30%（当前）** | **11 个月** |
| 40% | 9 个月 |
| 50% | 8 个月 |

**发现 2**：30% 节奏 + 10% 硬顶 → 约 11 个月投完，期间现金占 74%→5%，若市场年化 7%，平均现金拖累约 **3~4% 年化**。这与"10 年以上"的目标不冲突，但要确认你是否接受这样的慢节奏。

**建议**：把 `deployPacePct` 从 0.30 提到 **0.40~0.50**（仍受 10% 单次硬顶保护），约 8~9 个月完成；或维持 30%（更稳，但踏空风险更高）。
