# 估值模型确认书（2026-10-28）

目的：在投入 30 万之前，把「贵不贵」的判断依据摊开给你看——每个资产用什么指标、数据从哪来、阈值为什么这么定、哪里不可靠、怎么验证。

## 1. 结论先说

| 资产 | 我们的判断依据 | 它到底是不是"估值" | 置信度 |
| --- | --- | --- | --- |
| A 股（宽基/红利/医药/消费） | 盈米市场温度计（PE+PB+风险溢价加权，0–100） | **是**，官方口径 | **高** |
| 港股 / 中概 | 距近 1 年最高净值的回撤 | **不是估值**，是回撤/动量代理 | 中低 |
| 美股（标普500） | 距近 1 年最高净值的回撤 | **不是估值**，是回撤/动量代理 | 低 |
| 黄金 | 距近 1 年高点的回撤 + 长期涨幅 | **不是估值**，黄金没有 PE | 低 |
| 债券（1-3 年） | 不判断，直接买 | — | — |
| 债券（7-10 年） | 净值回撤 ≥3% 才加 | 收益率的**代理**，不是收益率本身 | 低 |

**一句话：真正"估值"的只有 A 股那一条；其余是"位置/回撤"判断，用来控制买入节奏，不是估值。** 这一点必须说清楚，否则容易误以为我们在用一套统一的估值模型。

## 2. A 股温度计：已验证的口径

盈米且慢投研部的公开说明（[市场温度计专栏](https://content.qieman.com/content/article?articleId=1810)）：

> 采用市场指数成立以来的**所有市盈率、市净率、风险溢价**数据作为编制指标，赋权加权计算；理论区间 0–100℃；**30℃ 以下为低估，70℃ 以上为高估**。

当前值（2026-10-28）：

| 指数 | 温度 | 官方档位 |
| --- | ---: | --- |
| 中证全A（000985） | **12.83°** | 低估 |
| 沪深300（000300） | **7.55°** | 低估 |
| 中证500（000905） | 36.63° | 合理 |

**需要的修正**：我前面用的分档是"<15 便宜、>60 贵"，与官方口径不一致。应为：

| 档位 | 温度 | 动作 |
| --- | ---: | --- |
| 极低估 | < 10 | 买满剩余额度 |
| 低估 | 10–30 | 买 2/3 |
| 合理 | 30–50 | 买 1/3（慢） |
| 偏高 | 50–70 | 买 1/4 或 0 |
| 高估 | > 70 | 不买 |

按这个修正，现在中证全A 12.83° 属于"低估"（不是极低估），A 股部分应买 2/3，而不是我之前写的"买满"。

## 3. 非 A 股资产：诚实标注这是"回撤代理"

已核对的数据（一年窗口，2025-10-28 → 2026-10-28）：

| 标的 | 现价 | 1 年高点（日期） | 回撤 |
| --- | ---: | ---: | ---: |
| 050025 标普500 | 5.5812 | 5.6578（2026-10-09） | **−1.35%** |
| 000216 黄金 | 3.0027 | 4.2992（2026-01-29） | **−30.16%** |
| 000071 恒生 | 1.3602 | 1.6833（2026-01-29） | **−19.19%** |
| 100032 红利增强 | 0.9540 | 1.0690（2025-11-13） | **−10.76%** |

局限（必须知道）：
1. 只是"距 1 年高点"，不是"距历史高点"——标普 500、黄金的 1 年高点很可能就是历史高点，但红利/港股不是；
2. 回撤 ≠ 贵：美股从高点回撤 1.35% 可能依然很贵（CAPE 高），港股跌 19% 也可能只是便宜了一点点；**它只回答"现在买是不是比高点便宜"，不回答"绝对值贵不贵"**；
3. 没有考虑汇率、溢价、QDII 额度。

**我还验证了一件事：盈米 `GetFundDiagnosis` 里的 valuation 字段不可用。** 标普500（距高点 1.35%）和黄金（距高点 30%）的返回都是"处于历史低位，低于 100% 的时期"——这是模板文案，不是真实分位。所以我没有用它做判断。

## 4. 债券：只有代理，没有收益率

- 1-3 年短债：久期短，收益率波动对净值影响小 → 不择时，直接买；
- 7-10 年长债：真正该看的是 **10 年期国债收益率分位**，但盈米 MCP 没暴露这个数据。现在用的是"净值回撤 ≥3% 才加一批"，等价于"收益率从低点回升约 0.2–0.3%"——方向对，但粗糙。
- 改进：每月查一次中债 10 年期国债收益率（外部数据），<2.5% 只做短债，2.5–3.0% 正常配，>3.0% 加长久期。

## 5. 这套模型的五个已知缺陷

1. **只有 A 股是真估值**：海外/黄金/债券都是代理指标（回撤/久期），置信度低；
2. **没有历史回测**：温度计没有公开历史序列，我无法验证"温度<30 买、>70 停"在 A 股的实际超额收益；只能引用官方口径 + 逻辑；
3. **可能频繁翻转**：价格在阈值附近震荡会导致反复买卖。解决：加**滞后带（hysteresis）**——买入阈值和停止阈值分开（例如温度 <30 才买、>40 才停），并且**每月最多执行一次**，不按日盯盘；
4. **单点数据**：温度计是"当前值"，没有趋势和分位构成（PE/PB/风险溢价各占多少权重未公开），无法判断"低估还会持续多久"；
5. **行业层缺失**：温度只有 3 个宽基指数，红利/医药/消费没有各自的温度，只能用"宽基温度 + 自身回撤"近似——这是为什么我在 30 万方案里对 A 股是"按宽基温度统一买"，而不是逐个行业择时。

## 6. 如果你想让它更硬：三个可选升级

| 升级 | 做法 | 成本 |
| --- | --- | --- |
| ① 200 日均线（趋势锚） | 用 MCP 拉 1 年净值，算 NAV 与 200DMA 的偏离（黄金/美股/港股均可用），比"距高点回撤"更平滑、少翻转 | 低，可在插件里自动算 |
| ② 美股真估值 | 引入 S&P500 的 CAPE / 盈利收益率（外部数据源，每月一次） | 中，需手动或新增数据源 |
| ③ 债券收益率 | 引入中债 10 年期国债收益率分位，替代"回撤代理" | 低，每月手动查一次 |

我建议至少做 ①（把回撤换成"200 日均线偏离 + 回撤"双条件），因为它能显著降低"刚跌 10% 就买"的假信号。

## 7. 验证计划（在投 30 万之前 / 同时）

建议按这个顺序验证，而不是先信后投：

1. **纸上演练 8–12 周**：每周记录一次温度 + 各标的回撤 + 模型给出的动作，**不下单**；观察信号是否频繁翻转、是否捕捉到明显的便宜/贵；
2. **小资金实盘**：先用 2–3 万按规则跑 1–2 个月，验证执行层面的问题（QDII 限额、申购费、到账时间）；
3. **对照基准**：同时记录"如果当天一次性买满"的成本，事后比较模型是否真的买得更便宜；
4. **通过后再放大到 30 万**；不通过就调阈值或换模型（见第 8 节）。

## 8. 如果你不认可这个模型，有三条替代路线

| 路线 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A. 固定比例 + 再平衡 | 不看贵贱，30 万按目标权重一次/分批买入，之后按偏离 ±5pp 再平衡 | 简单、可回测、不依赖估值判断 | 会在高位买入；没有"等便宜"的收益 |
| B. 目标风险 | 用波动率控制仓位（如年化波动目标 8%），波动升高自动降权益 | 风险可控 | 仍不解决"贵" |
| C. 趋势跟随 | 200 日均线上方持有、下方减仓 | 天然规避大熊市 | 震荡市来回打脸、交易成本高 |

当前这套"温度 + 回撤"是介于 A 与 C 之间的折中：**A 股用估值、其他用位置**。如果你更信"便宜才买"，就补 ①③；如果你更信纪律，就直接走 A。

## 13. 模型正式定义：战略配置 + 估值驱动的战术超配（2026-10-29）

模型是**两层结构**，不是"目标比例可以随便漂"的单层规则：

### 13.1 战略层（锚，不可忽略）
- 每个品种有明确的战略权重（**15 只，v7.2**）：红利 28（100032 9 / 008163 7 / 009051 6 / 020602 6）、A股其他 13（022424 6 / 000248 3 / 162412 4）、海外 10（050025 4 / 000071 2 / 006327 4）、黄金 5（000216）、债券 39（007169 28 / 003376 6 / 001257 5）、现金 5（000509）；
- 战略权重是**锚**：所有买卖、偏离评价、压力预算都以它为基准；
- 红利在 20–25% 区间内由温度微调（<10° 取 25、>50° 取 20），但仍在战略框架内。

### 13.2 战术层（估值驱动的超配带）
- 只有档位为**极低估 / 便宜**的品种才允许超配；
- 超配上限 = min(战略权重 × 115%，战略权重 + 该类战术带)：
  - A股 +1.5pp、海外 +0.75pp、黄金 +0.5pp、债券 0（2026-10-29 波动放大后收紧）；
- 单笔买入仍受组合 10% 上限、单只每次买缺口 50% 限制；
- 风险资产（A股+海外+黄金）总仓位硬上限 **65%**。

### 13.3 层级标签（输出里可见）
| 标签 | 含义 |
| --- | --- |
| 战略补缺口 | 当前 < 战略锚，按缺口补 |
| 战术超配（估值驱动） | 当前 > 战略锚，但因便宜而保留 |
| 超战略锚（不卖） | 当前 > 战略锚但档位不到"贵" → 只记录，不卖出 |

### 13.4 回归规则（2026-10-29 收紧）
- **只有档位「贵」且超配 >0.5pp 才卖**（卖回战略锚）；
- 「偏高 / 合理 / 低估 / 极低估」即使超配也**先不卖**，只记录在"超配但非贵（不卖）"清单；
- 每次 `rebalance` 优先按战略缺口分配，再考虑战术带内超配。

### 13.5 当前实测（2026-10-29，15.6 万）
- A股当前 30.61%，战略 28%，战术带上限 32% → 只剩 1.39pp 加仓空间；
- 海外/黄金当前 0%，空间充足；
- 本次建议：债券 11,666 + 黄金/海外 便宜超配 ≈ 3,027 + A股 小补 905，合计 15,599（单次上限）。

| 中证全A 温度 | 现金目标 |
| --- | ---: |
| <10° | 5% |
| 10–30° | 10% |

### 14.2 横截面优先买（借鉴"挑最便宜的买"）
- 档位优先级：极低估/便宜 1.6 ＞ 低估 1.2 ＞ 偏低 1.15 ＞ 合理偏低 1.0 ＞ 合理 0.8 ＞ 偏高 0.25 ＞ 贵 0；

## 15. 风格/行业指数的估值修正（2026-10-30）

问题：盈米温度计只有 3 个宽基（中证全A 9.39°、沪深300 7.66°、中证500 27.5°），没有红利/医药/消费等风格行业温度。此前所有 A 股品种都套用全A温度 → **红利明明是近期上涨、位置不低，却被判成"极低估"**。

修正：风格/行业品种（红利 4 只、消费、医药、医疗）同时计算两个信号——
- **温度档位**（宽基温度，代理市场整体估值）；
- **自身位置档位**（该基金 1 年高点回撤 + 200 日线偏离）。

取**更保守者**（档位比例更低的一方）。实测效果：

| 品种 | 温度档位 | 自身位置 | 最终档位 |
| --- | --- | --- | --- |
| 100032 红利增强 | 极低估（9.39°） | 合理偏低 | **合理偏低（1/3）** |
| 009051 / 001180 等 | 极低估 | 合理偏低 | 合理偏低（1/3） |
| 000216 黄金 | —（位置信号） | 便宜 | 便宜（封顶 1/2） |

配置 `combineStyleValuation: true`（默认开）。宽基 A500 仍以沪深300温度为主，同时参与位置信号校验。

## 18. 黄金专用：多年位置 + 均线趋势闸门（2026-11-03）

### 为什么单看 200 日均线对黄金不够
200 日均线只是"趋势代理"，不是估值：
- 黄金的周期是**多年**级别，1 年高点/回撤窗口太短（2026-02 的高点 5,411 是多年高位，1 年窗口会把"历史高位"误当常态）；
- 单条 200 日线在震荡市会反复穿越，容易在下跌中段给出"便宜"的假信号；
- 黄金的真实驱动是实际利率/美元/央行购金，公开免费源拿不到实时实际利率。

### 现在用的组合判断
1. **位置**：用 COMEX 美元金价（`101.GC00Y`，已天然剔除汇率）的**3 年区间**——距 3 年高点回撤 + 距 200 日线偏离，套用原有六档；
2. **趋势闸门**：20/60/200 日线排列 + 20 日/200 日线斜率：
   - 空头排列且均线走低 → **下跌**，单次上限 **1/4**；
   - 多头排列且均线走高 → **上涨**，恢复 **1/2**；
   - 其余 → **震荡**，上限 **3/8**；
3. 最终比例 = min(位置档位比例, 趋势上限)，再套黄金封顶 1/2。

### 当前实测（2026-11-03）
- COMEX 金 3,926.5，3 年高 5,411 → **距高 −27.43%**，距 200 日线 **−12.81%**；
- MA20/60/200 = 4,095 / 4,304 / 4,503 → **空头排列**，20 日均线斜率 −1.26%、200 日线 −1.12%；
- 位置判"便宜"（1.0），趋势判"下跌"（上限 0.25）→ **最终 0.25**：黄金单次最多买剩余额度的 1/4（之前是 1/2）。

配置：`goldTrendGate: true`、`goldIndexSecid: 101.GC00Y`、`goldLookbackLimit: 760`。
